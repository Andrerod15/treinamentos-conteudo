# treinamentos-conteudo
Treinamento de códigos para aprendizado

## 📊 Dados Utilizados

Os dados utilizados neste projeto são referentes ao programa **Bolsa Família**, obtidos a partir dos dados públicos disponibilizados pelo Governo Federal.

Devido ao tamanho do arquivo, o dataset tratado não está incluído neste repositório.  
Ele pode ser acessado através do link abaixo:

🔗 [Download do arquivo parquet tratado no Google Drive](https://drive.google.com/drive/folders/1mPiNF3Njli8Mm4wQ3yoJeO0odYcF6-0-)

**Nome do arquivo:** `bolsapl_tratado.parquet`  
**Formato:** Parquet (`.parquet`)  
**Tamanho aproximado:** 500mb - 1Gb  
**Descrição:** Contém dois meses de pagamentos do Bolsa Família concatenados e tratados em Polars.
